# Project Workflow Guide  

Welcome to the project! Please follow these guidelines to ensure smooth collaboration and avoid conflicts.  

## Getting Started  

1. **Clone the Repository:**  
   Start by cloning the project to your local machine:  
   ```bash
   git clone <repository_url>

2. **Always Pull the Latest Changes:**
    To avoid conflicts, ensure your local repository is up-to-date by running:
   `` git pull origin main``
   please do that whenever you want to start the project and when you are done with your section

3. **After that create a Branch**
    ``git checkout -b anyname you want
4. **Commit Regularly:**
    Commit your changes with clear and descriptive messages:
    ``git commit -m " anything you want"git 
5. **After Completing Your Work**
    Pull Again to Sync with the Latest Updates:
    Before pushing your branch, pull the latest changes to prevent conflicts:
    ``git pull origin (this should be the name of the branch you created)
6. **Push Your Changes:**
    Push your branch to the repository:
    git push origin <branch_name>
